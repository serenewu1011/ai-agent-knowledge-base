## 這篇在說什麼

AI Agent（人工智慧代理）是一種以 AI 模型為核心、能依照目標處理步驟的系統。模型負責理解輸入或產生判斷，程式則提供工具、資料和執行規則。

## 核心概念

一個常見的 Agent 系統可以包含以下部分：

- **模型**：理解文字、整理資訊或選擇下一步。
- **工具**：讓系統查詢資料或執行動作，例如呼叫 API。
- **流程控制**：限制哪些工具能用、何時需要補問，以及結果如何回覆。
- **狀態或資料**：保存完成任務所需的資訊；實際保存方式依系統設計而不同。

Agent 不代表模型可以不受限制地操作所有資料。實務上，系統應明確定義模型負責的判斷，以及程式負責的驗證和執行。

## 會議助理中的例子

使用者說「幫我安排下週的會議」時，模型可以協助理解這句話的意圖或擷取日期等資訊。系統仍需要由程式檢查必要欄位、建立正確資料，並在資訊不足時請使用者補充。

在這個專案中，LINE 和 LIFF 提供使用者操作入口；後端與資料庫負責實際的資料處理。模型在系統中的確切責任，會另外在意圖辨識文章中說明。

## 開發注意事項

- 先列出系統必須完成的任務，再決定哪些步驟值得交給模型判斷。
- 對寫入資料或通知使用者等動作，應由程式檢查權限與必要欄位。
- 需要可靠結果時，將模型輸出限制成可驗證的格式，並處理無法判斷的情況。
- 「使用了 LLM」不等於「系統已具備完整 Agent 能力」；仍需看它是否有清楚的工具、流程與錯誤處理。
